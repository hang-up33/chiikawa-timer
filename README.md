# chiikawa-timer

ちいかわの「パジャマパーティーズのうた」が流れる、パジャマパーティー気分のタイマーアプリです。

## 使い方

`index.html` を直接ブラウザで開く(`file://`)と、YouTube IFrame Player が
オリジンを要求するため動画が再生できません(プレーヤーエラー153)。
ローカルサーバー経由で開いてください(ビルドは不要です)。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

1. 時間・分・秒を入力します(最大24時間まで)
2. 「スタート」でタイマー開始。実行中は「パジャマパーティーズのうた」がループ再生されます
3. 「一時停止」「リセット」で操作できます
4. タイマー終了時に画面表示と通知でお知らせします

## 楽曲について(著作権に関する注記)

このアプリは「パジャマパーティーズのうた」の音源ファイルを一切同梱・配布していません。
再生には YouTube の公式配信元(Pony Canyon)による動画を、YouTube IFrame Player API を使って
埋め込み表示・制御しているのみです。

- 楽曲: 「パジャマパーティーズのうた」(TVアニメ『ちいかわ』挿入歌)
- 権利表記: ©ちいかわ製作委員会・Pony Canyon

埋め込み元の動画が削除・非公開になった場合は再生できなくなります。あらかじめご了承ください。

## バックグラウンド再生について

画面ロックやアプリの切り替えで完全にバックグラウンドになっている間、音楽が鳴り続けることは保証していません
(タブに戻った際に自動再開する対応のみ実装済み)。音源を独立した`<audio>`要素として扱えば実現しやすくなりますが、
このアプリは楽曲ファイルを配布せずYouTube公式の埋め込みプレーヤー(iframe)経由でのみ再生する方針(上記の著作権
に関する注記)のため、クロスオリジンiframe内部の再生継続はブラウザ/OS側のポリシー(特にiOS Safari)に委ねられ、
アプリ側での制御は困難です。
