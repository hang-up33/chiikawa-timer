# chiikawa-timer

ちいかわの「パジャマパーティーズのうた」が流れる、パジャマパーティー気分のタイマーアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します(ビルド不要)。

1. 時間・分・秒を入力します(最大24時間まで)
2. 「スタート」でタイマー開始。実行中は「パジャマパーティーズのうた」がループ再生されます
3. 「一時停止」「リセット」で操作できます
4. タイマー終了時に画面表示と通知でお知らせします

## 楽曲について(著作権に関する注記)

このアプリは「パジャマパーティーズのうた」の音源ファイルを一切同梱・配布していません。
再生には YouTube の公式配信元(Pony Canyon)による動画を、YouTube IFrame Player API を使って
埋め込み表示・制御しているのみです。
