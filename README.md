# chiikawa-timer

ちいかわの「パジャマパーティーズのうた」が流れる、パジャマパーティー気分のタイマーアプリです。

## 使い方

`index.html` を直接ブラウザで開く(`file://`)と、YouTube IFrame Player が
オリジンを要求するため動画が再生できません(プレーヤーエラー153)。
ローカルサーバー経由で開いてください(ビルドは不要です)。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

1. 時間・分・秒を入力します(最大24時間まで)
2. 「スタート」でタイマー開始。実行中は「パジャマパーティーズのうた」がループ再生されます
3. 「一時停止」「リセット」で操作できます
4. 「🎵 曲をえらぶ」で再生する曲を切り替えられます(実行中に切り替えるとすぐ新しい曲が流れます。選択はブラウザに保存されます)
   - パジャマパーティーズのうた
   - 島のうた (セイレーンver.)
5. タイマー終了時に効果音・画面表示・通知でお知らせします
   - 効果音は『映画ちいかわ 人魚の島のひみつ』WEBCM(東宝MOVIEチャンネル公式)のうさぎの声の部分を、埋め込みプレーヤーで再生します
   - 再生できない場合(画面ロック中など)は、うさぎ風の合成音を鳴らします

## 楽曲について(著作権に関する注記)

このアプリは楽曲の音源ファイルを一切同梱・配布していません。
再生には YouTube の公式配信元による動画を、YouTube IFrame Player API を使って
埋め込み表示・制御しているのみです。

- 楽曲: 「パジャマパーティーズのうた」(TVアニメ『ちいかわ』挿入歌)
- 楽曲: 「島のうた (セイレーンver.)」(TVアニメ『ちいかわ』)
- 終了音: 『映画ちいかわ 人魚の島のひみつ』WEBCM うさぎラップ篇(東宝MOVIEチャンネル)
